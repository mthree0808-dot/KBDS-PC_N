# Figma 재사용 스크립트

- `clone-screen.js`는 이 작업 묶음에서 실제 사용한 화면 복제 흐름(페이지 전환 → 현재 폰트 로드 → clone → 같은 부모에 우측 배치)을 함수로 정리한 시작 헬퍼다.
- 입력: `{pageId, templateNodeId, rightOfNodeId, name, canvasGap?}`. ID는 현재 파일에서 확인한 값을 전달한다. 템플릿에는 검증된 헤더·푸터가 포함되어 있어야 한다.
- 해당 Figma 스킬과 필수 지침을 먼저 읽는다. Figma 작업 세션을 만들고 `use_figma`의 code에 파일 내용과 `return await cloneScreen(figma, DATA);`를 연결한다. DATA는 JSON 객체로 전달한다.
- 이 헬퍼는 화면 복제만 담당한다. 반환한 BODY ID 아래에 해당 화면의 기획 데이터로 콘텐츠를 구성한다. 복제된 이전 BODY 문구가 남은 상태를 완료로 보고하지 않는다.
- 검증 상태: 복제 흐름은 기존 Figma 화면 제작에서 사용·확인했고, 저장된 헬퍼 자체는 정적 구문 검사를 수행했다. 일반 입력 폼·확인·완료 등 모든 화면의 제작을 자동화하는 전체 빌더로 검증된 것은 아니다.
- 새 빌더를 추가할 때 실제 Figma에서 통과한 구조·서체·화면 검수 범위를 파일 설명에 기록한다. 검증된 빌더는 문구·값·선택 상태를 입력 데이터로 분리한다.
- 자산은 `design-system/component-map.json`, 디자인 스펙은 `design-rules.md`, 작업 운영은 `AGENTS.md`를 따른다.
- 실행은 Figma 네이티브 인스턴스를 유지한다. 예시 화면 링크나 고객 개인정보를 스크립트·데이터 파일에 저장하지 않는다.
